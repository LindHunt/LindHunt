## About

Active in the field of Cyber Security, continuously expanding knowledge and skills across **Web Application Security**, **Offensive Security**, **Threat Intelligence**, **OSINT**, and **SOCMINT**.

Core activities include attack surface analysis, vulnerability identification and validation, vulnerability research, penetration testing, and OSINT/SOCMINT investigations.

Security research has been recognized by multiple international organizations and institutions, including credit for the discovery of `CVE-2026-18741` and `CVE-2026-26211`.
